# One Trini Runna: Performance Elevated

Design a premium, high-converting e-commerce website for ONE TRINI RUNNA, a modern performance running apparel and athletic gear brand.

BRAND POSITIONING:

ONE TRINI RUNNA creates high-performance running apparel, accessories, and training gear for runners who want to move faster, train harder, and look confident while doing it.

The brand should feel like a combination of Nike Running, Tracksmith, Lululemon, and a modern streetwear performance brand — but with its own distinctive identity.

CORE BRAND MESSAGE:

RUN STRONG. MOVE FREE. PERFORM BETTER.

TARGET AUDIENCE:

Runners, athletes, fitness enthusiasts, recreational runners, serious runners, marathoners, active lifestyle customers, and people who want athletic clothing that looks premium both during workouts and everyday life.

DESIGN DIRECTION:

Create an Awwwards-level premium athletic e-commerce experience.

Use:

- Black / near-black

- White

- Strong performance red as the primary accent

- Very subtle gray tones

- Large cinematic athlete photography

- Bold condensed athletic typography

- Oversized headlines

- Strong visual hierarchy

- Clean product photography

- Sharp geometric layouts

- Generous spacing

- Subtle motion and micro-interactions

Do NOT make the website look like a generic clothing store.

It should feel energetic, premium, editorial, athletic, aspirational, and performance-driven.

DESIGN DETAILS:

- Use oversized typography throughout.

- Use red only for emphasis and conversion elements.

- Keep backgrounds predominantly black and white.

- Use photography as a major part of the design.

- Use rounded corners sparingly; favor clean athletic geometry.

- Use subtle shadows rather than heavy effects.

- Add smooth hover states.

- Add tasteful scroll animations.

- Use parallax effects on major lifestyle imagery.

- Use image reveal animations when sections enter the viewport.

- Keep animations fast, smooth, and premium.

- Make the website feel extremely polished on desktop, tablet, and mobile.

MOBILE EXPERIENCE:

Design mobile-first responsive layouts.

Use a clean hamburger menu.

Make product cards easy to browse with horizontal scrolling where appropriate.

Keep CTA buttons large and thumb-friendly.

Use sticky add-to-cart on product pages.

Ensure typography remains bold and impactful without overwhelming the screen.

IMPORTANT:

Do not simply copy the reference layout.

Use the reference as inspiration for the brand's athletic energy, dark/light contrast, red accent color, typography, photography, and premium e-commerce feel.

Create a unique ONE TRINI RUNNA visual identity that feels like a serious international performance running brand.

The final result should look like a premium $50,000+ athletic e-commerce website rather than a template.
